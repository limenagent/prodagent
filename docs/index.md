# 你会用 LangChain，但你能设计一个 Agent 平台吗

为什么值得花时间学，README 里讲过了。这一页只回答一个问题：**怎么学**。

Agent 从 demo 到生产之间的问题，归纳起来五组。每组问题下面，标注了回答它的章节——这也是整个文档的目录。

## 五组问题，五章地图

**运行时稳定性**

- 进程被 kill -9，怎么从断点续跑，不丢状态、不重复执行？——[崩溃恢复](topics/recovery.md)
- 模型在工具间反复横跳，怎么在 turns/seconds/tokens/cost 四维同时设硬上限？子 Agent 的钱怎么实时汇总？——[预算](topics/budget.md)
- HIGH 副作用工具要删数据，怎么挂起等人审？拒绝之后怎么增量重规划？——[审批](topics/approval.md)

**上下文与记忆**

- 第 30 轮上下文塞不下了，丢哪段？语义损失边界在哪？——[压缩](topics/compression.md)
- 规则、实体、精确事实、语义相似四类信息，怎么并行召回再冲突裁决？——[记忆](topics/memory.md)
- 同类任务处理第三次，轮数能不能不减？——[技能](topics/skills.md)

**多 Agent 协作与治理**

- 五个 Agent 并行，消息怎么去重、契约校验、审计、死信？怎么不丢不重不乱序？——[协作](tour/07-multiagent.md)、[策略与治理](topics/governance.md)
- 十个团队共用平台怎么做隔离？RBAC 之外怎么做到操作级授权？——[策略与治理](topics/governance.md)

**可观测与评估**

- 出了问题，怎么定位是模型、prompt 还是工具的错？——[可观测](topics/observability.md)
- 改了一版 prompt，怎么知道变好还是变差？——[评估](topics/evaluation.md)

**怎么下手**——[上手](start.md)，半小时跑通裸核、打开生产开关、进 playground。

## 第一部分：先建立完整心智模型

问题域章节之前，建议先走[第一部分 · 一次调用的生命周期](tour/index.md)：跟着一次 `chat()` 调用，七站读穿内核——词汇、契约、模型、工具、循环、规划、协作。第一站就是一个独立成篇的 `kernel/` 包：七个模块、约两千行、不 import 任何能力包（有 CI 测试钉死这一点）——读完它你就握住了全部理论，后面的每一站都是往插槽上挂能力。读完你能在白纸上画出 Agent 的运行时架构，说清每一层为什么存在、去掉会怎样。后面所有专题，都是在这张图上往不同角落里钉护甲。

附录（取舍、术语、API 参考）是查阅材料，不是读物。
