# 附录 · 跨章知识点速查

全书的基础知识都散在各章的"补课"小节里，按需教的。这里把它们集中成一张索引：忘了某个概念，查到这里，回到那一章复习。每条给一句话提示和出处。

零基础的读者怎么用这份附录：不用从头背。它更像一本字典——你在正文里读到某个词卡住了，回到这里按分类查那一行，先看"一句话"找回印象，再点章节链接回到它第一次被讲透的地方。这些概念你不需要一次全记住，每读完一章，回来扫一眼对应分类，会发现表里的行越来越眼熟，这就是掌握的过程。

## 标本框架的十条设计原则

框架的设计哲学原文有十条，每条在正文都有完整论证，这里是索引：

| # | 原则 | 一句话 | 章节 |
|---|------|--------|------|
| 一 | 裸核默认，生产一键 | 默认零依赖可跑，`production()` 一行换全套护甲 | [1.2](ch01.md) |
| 二 | 纯内核 | 发动机从整车里拆出来：kernel 不做 IO、不依赖能力包 | [1.2](ch01.md)、[3.6](ch03.md) |
| 三 | 三协议总线 | 观察并发扇出、收集按序汇总、否决 fail-closed | [11.2](ch11.md) |
| 四 | 四轴预算互为兜底 | 轮数/时间/token/钱各度量一种失控 | [4.2](ch04.md) |
| 五 | 结构化错误而非异常 | 模型会犯错是常态，给它看着错误改正的机会 | [5.4](ch05.md)、[2.8](ch02.md) |
| 六 | 压缩有明确边界 | 按占比分级牺牲，系统提示永不压缩 | [6.2](ch06.md) |

| 十 | 全离线可复现 | 理解一个机制最深刻的方式是调试它 | [11.6](ch11.md) |

## 关键取舍速查

正文讲了每个机制"是什么"，这里收录最重要的"为什么不选另一种"：

| 取舍 | 不选的那种，输在哪 | 章节 |
|------|-------------------|------|
| Protocol 而非 ABC | 假件被迫继承框架基类，第三方类无法零修改加入 | [2.2](ch02.md) |
| 核心只 4 个依赖 | 每个厂商 SDK、每个数据库驱动都是安装冲突与漏洞面 | [1.2](ch01.md) |
| kernel 与 runtime 分离 | 循环逻辑与装配逻辑混住，两种模式边界不清 | [3.6](ch03.md) |
| Message 用 OpenAI 线格式为规范 | 自创中立格式要多一层"框架语"，全行业要重学；Anthropic 适配器单点翻译 | [2.5](ch02.md) |
| StopReason 用 Anthropic 词汇为规范 | 消息与停止原因各取事实上的业界通用语，不单选一家 | [2.5](ch02.md) |
| thinking 块原样往返（含签名） | 只存纯文本会丢签名，工具续轮时 API 直接拒绝 | [2.5](ch02.md) |
| 四轴而非一轴 | `max_iterations` 度量不了成本：同轮数账单可差三个数量级 | [4.1](ch04.md) |
| 恢复用快照+事件日志两条腿 | 纯快照丢历史，纯重放太慢；混合恢复取两者之长 | [7.7](ch07.md) |
| AgentSpec 与 AgentConfig 分离 | 配置带活对象序列化不了，规格要跨进程；混在一起两头不讨好 | [10.5](ch10.md) |
| 执行器默认不重试 | 盲目重试烧钱推迟失败；有上下文的模型才是错误的最佳处理者 | [5.6](ch05.md) |
| 熔断用滑动窗口而非累计计数 | 半年前失败两次加今天一次不该熔断；衡量"最近"而非"历史" | [5.6](ch05.md) |
| 重规划版本化而非重画 | 已完成步骤有副作用不可重执行；被覆盖的图答不了审计 | [8.4](ch08.md) |

## 术语表

| 术语 | 定义 |
|------|------|
| Agent | 有身份、系统提示、工具集的实体；无状态配置对象，可并发跑多个 Run |
| Run | 一次任务执行的完整生命周期；有状态、可序列化 |
| Turn | 轮原子：一次模型调用 + 至多一轮工具执行 |
| NodeStatus | 工作单元的六态：PENDING/RUNNING/COMPLETED/FAILED/SUSPENDED/OBSOLETE；OBSOLETE 是被新版本顶替，既没跑过也没失败，不同于 FAILED |
| Turn | 模型的一次输出 |
| Message | 对话历史中的一条消息 |
| ToolCall / ToolResult | 模型的工具请求 / 工具的返回 |
| ToolOutcome | 工具结局：OK/RETRY/ABORT/BLOCKED/SUSPENDED/HANDOFF |
| StopReason | 停止原因：END_TURN/TOOL_USE/MAX_TOKENS/CONTENT_FILTER |
| AgentSpec | Agent 的可序列化投影，跨进程传递用 |
| ExecutionMode | REACTIVE（边走边想，默认）/ PLAN_FIRST（先规划后执行） |
| Workflow | 手写确定性 DAG 的构建器（不是第三种执行模式） |
| Plan / Node | 编译后的 DAG / 图中一个节点 |
| ToolMeta | 工具静态档案：副作用等级、超时、幂等、域 |
| SideEffectLevel | LOW / MEDIUM / HIGH；只读是独立布尔，不是第四级 |
| HardBudget | 四轴上限：turns / seconds / tokens / cost |
| BudgetLedger | 共享账本，三阶段记账 reserve / commit / release |
| billable_tokens | 计费 token = 总量 − 缓存读 |
| CompressionLevel | 五级压缩：NONE → 紧急 |
| ContextBudget | 窗口分层预算：系统 8% / 状态 15% / 记忆技能 35% / 历史 42% |
| Spill | 超长工具结果溢出存储，带内留预览与取件指引 |
| checkpoint | 运行状态快照，每轮落盘，乐观并发写 |
| 事件日志 | 只增不改的追加流水，审计与重放的事实源 |
| 幂等键 | 崩溃稳定的调用标识，重复执行的识别凭据 |
| cassette | 回放录像带：边界问答对 + 版本指纹 + 哈希链（施工中） |
| HookBundle | 自装配墨盒：一个能力打包自己挂到总线 |
| StageDriver | 三种循环共用的驱动器：共享循环外围，不共享循环体 |
| Crossing | 统一消息信封，过五段管道（去重/契约/截断/Gate/死信） |
| AgentSpan | 决策快照：身份位置 + 决策上下文 + 结果成本 |
| trace / span | 一条调用链 / 链上一个动作的记录 |
