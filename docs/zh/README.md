# prodagent 文档导览

这里不讲“怎么调用某个 API”，那看[仓库 README](https://github.com/limenagent/prodagent) 和 `examples/` 就够了。
这里回答另一类问题：**这个内核为什么长成这样、每个部件在解决什么矛盾、还能怎么选。**

文档按“一台机器怎么一步步长出来”的顺序排列，每一篇都建立在上一篇之上，零基础也能顺着
读下来。你不需要先会 LangGraph，也不需要提前背术语——每个词第一次出现都会先用大白话解释。

## 建议的阅读顺序

**第一步，先建立全貌（约 15 分钟）**

1. [架构总览：从六行循环到一台机器](architecture.md)——一张图看清六个部件，以及它们
   为什么缺一不可。

**然后动手让它长在手上（约 30 分钟，强烈建议）：**
[手写一个最小内核](build-a-minimal-kernel.md)——大约 80 行、只用标准库，不用装任何东西。
亲手把波次循环敲一遍，再看下面的设计取舍，就像在复习而不是学新名词。

**第二步，看五个最关键的设计取舍（每篇 5–8 分钟）**

2. [蓝图与一次执行为什么要分开](design/01-plan-and-run.md)
3. [状态为什么是事件“折叠”出来的](design/02-state-from-events.md)
4. [波次：为什么它是一致性边界](design/03-waves.md)
5. [为什么内核里没有 ReAct](design/04-no-pattern-in-kernel.md)
6. [为什么多 Agent 不需要新引擎](design/05-multi-agent.md)

**第三步，横向对照与答疑**

7. [和 LangGraph / ADK / CrewAI 的概念对照](../zh/comparison.md)——如果你用过别的框架，
   从这张表迁移最快。
8. [示例导览](examples.md)——每个例子在演示什么、你该重点观察什么。
9. [常见问题](faq.md)
10. [术语表](glossary.md)

## 三种读者，三种读法

- **第一次接触 Agent 框架**：严格按上面顺序读，遇到代码先不求甚解，抓住“为什么需要它”。
- **用过 LangGraph / ADK，想搞懂底层**：先读[架构总览](architecture.md)，再直接看
  [概念对照表](comparison.md)，然后挑你最熟的那部分对照设计说明。
- **想读源码**：配合 README 的“建议的阅读顺序”，读到哪个文件，就回这里看对应的“为什么”。

## 这套文档不覆盖什么

为了保持“小而能读完”，这里只讲机制和取舍，不做逐步的手把手实现，也不展开压缩、检索等
可替换策略的具体算法——那些会在配套的极客时间专栏《生产级 Agent 框架设计与实现》里，从六行
循环开始一步一步推导和落地。这里给你的是**地图和风景**，专栏是**全程导游**。

English readers: start from [docs/en/README.md](../en/README.md).
