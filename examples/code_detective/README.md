# 代码侦探

---

> 示例 #5 —— 给 Agent 一个跑挂的测试，它自己读代码、试补丁、跑测试，修好还把经验记下来。

你甩给它一条报错："`test_login` 挂了"。然后它就像个真工程师一样干起活来。

它先读那个失败的测试，看它到底断言什么；再 grep 找到 `login` 函数在哪；读源码，发现密码
没加盐就存了。它提一版补丁，跑测试——还是挂。它不慌，读错误信息，发现项目里其实有个
`hash_with_salt` 没用上，改了再跑，这回过了。最后给你一份总结：根因是什么、怎么修的、
怎么验证的。

它还多做了一步：把这次修 bug 的套路记成一个"手册"存下来。下次遇到类似的登录失败，它
直接翻手册照着走，不用重新调试一遍。

它用的工具——读文件、搜代码、跑测试——都不是写死在代码里的，而是通过一个标准协议
桥接进来的。换个项目，工具能换，Agent 代码不用动。

## 本示例展示什么

- **多轮调试**：第一次没修好会读错误、换思路，而不是死磕同一个方案。
- **工具按标准协议接**：文件、搜索、测试都是外挂工具，可换、不绑死。
- **越修越聪明**：修过的 bug 沉淀成手册，下次同类问题直接照流程走。

| 提一次补丁就完事 | 代码侦探 |
|---|---|
| 改完就走 | 失败了读错误换思路，多轮修到好 |
| 工具写死在代码里 | 标准协议外挂，工具可换 |
| 修完不留痕 | 自动沉淀手册，下次直接用 |

代码在 `agent.py`，外挂工具在 `mcp_server.py`。
