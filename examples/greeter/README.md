# 问候

---

> 示例 #1 —— 最小可跑 Agent：一个名字、一个工具、一个模式，就能跑起来跟你打招呼。

很多人觉得搭一个 Agent 之前得先搞懂一大堆概念。这个例子只想说明一件事：最少三样东西
就能跑起来——给 Agent 起个名、给它一个能调的工具（这里就是"打招呼"）、告诉它用"边想
边做"的方式干活。

你说一句"跟世界打个招呼"，它就调那个工具，回你一句问候。没了。后面那些复杂的能力，都
是在这三样之上一点点加的。

## 本示例展示什么

- **一个 Agent 最少需要哪几块**：名字、系统提示、工具、执行模式，凑齐就能跑。
- **只读工具最安全**：这个工具只返回信息、不改外面世界，是最让人放心的那种。
- **不配也能看到过程**：什么钩子都不传，框架也会自动把每一步执行打印到终端，方便你看它
  到底干了啥。
